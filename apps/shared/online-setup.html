Connect Chess and Go online

This one-time setup is for the Sand Labs owner. Players will use the normal sign-in button afterward. Computer play already works without this setup.

1. Create the free project

Open Supabase, create a project called Sand Labs, select the Free plan and a European region. Keep your database password private.

In Authentication → URL Configuration, set your website URL to https://gkoromilas01.github.io/Sand-Labs-Public/ and allow these exact redirect URLs: https://gkoromilas01.github.io/Sand-Labs-Public/apps/chess/, https://gkoromilas01.github.io/Sand-Labs-Public/apps/chess/index.html, https://gkoromilas01.github.io/Sand-Labs-Public/apps/go/, and https://gkoromilas01.github.io/Sand-Labs-Public/apps/go/index.html.

2. Create the match database

Open the project's SQL Editor, create a new query, paste the database setup below, then Run. This creates the protected tables and functions used by the games.

3. Deploy the game service

In Edge Functions create board-games using the editor. Replace its code with the service below and deploy. Set the function’s Verify JWT switch off: this service verifies every player token itself. In Edge Function Secrets add SAND_ALLOWED_ORIGINS with the value https://gkoromilas01.github.io (no path or trailing slash). The service uses Supabase's built-in server credentials; never paste a service-role key into Sand Labs or this chat.

4. Connect Sand Labs

Send me the project's URL and publishable key from Project Settings → API. This public key is designed for the website. Do not send a secret key, service_role key or database password. I will install the connection and test two-player pairing.

Email sign-in needs no Google project. To add Google afterward, configure Google in Authentication → Sign In / Providers and enter your Google OAuth credentials there, inside Supabase.
