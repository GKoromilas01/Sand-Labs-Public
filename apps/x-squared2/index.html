How to use my X account

Automatic account connection is not available yet. Follow the steps below to start with your own tweet metrics.

Understand what works on your account

Add your own tweet metrics manually. Compare engagement per impression when impressions are available. Your 2,000+ followers are a starting audience; follower count alone does not establish monetization eligibility or income.

No X login, API connection, scraping, automatic posting or revenue forecast. Check X’s current official eligibility requirements before applying to its monetization programmes.

How to start with your X account

  1. Open X in another tab and choose 10–20 of your own recent posts from a similar period.
  2. Open each post’s analytics, if available, and copy its text, impressions, likes, replies and reposts into the form below. Leave impressions blank when unavailable.
  3. Click Add tweet, then Save on this browser. Download a JSON backup before changing devices.
  4. Compare topics with sufficient impressions. Try two different openings for your next posts and compare the results over the same reporting period.

Automatic connection — planned, not available yet

A real connection requires an X developer application, currently permitted API access, an HTTPS backend and OAuth authorization. Any API/hosting costs must be checked and approved first. GitHub Pages alone does not provide the required backend.

When the integration exists, authorization should open the official X page with read-only permissions. Never send your X password, developer secret or access token in chat or paste it into this page.
